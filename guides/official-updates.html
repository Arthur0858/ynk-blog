The family question

Can the family update a device without following a message link? Install updates from the device's official settings instead of message links. This guide is for a household where a message offers an update link outside the device's normal settings. For Install Updates From the Official Screen, the goal is one repeatable task the account owner understands, not a broad device overhaul.

Before you begin

Close the message, connect to trusted power and open the device's official update screen. Before changing anything for Install Updates From the Official Screen, agree on the exact result and keep a working contact method available in case the task needs to pause.

Three safe steps

1. Open settings directly.

Begin with the parent beside you and open settings directly. For install updates from the official screen, record the installed version, update source and basic functions tested afterward; keep passwords, recovery codes and private answers off the worksheet. The checkpoint is simple: the update completes from settings and the normal task still works.

2. Confirm power and backup.

Next, confirm power and backup. For install updates from the official screen, compare what appears on the device with the official guidance below, not with instructions from an incoming message or caller. Stop if the update requests payment, remote access or credentials in an unfamiliar page.

3. Test important functions afterward.

Finish by test important functions afterward. Ask the parent to repeat the result without coaching, then add the date beside the installed version, update source and basic functions tested afterward. If the install updates from the official screen task cannot be repeated, return to the last working state and use the official support route.

If it does not go as expected

Stop if the update requests payment, remote access or credentials in an unfamiliar page. While working on Install Updates From the Official Screen, a warning, unfamiliar login screen or unexpected request for private information is a reason to pause, document what is visible and return through an official support page.

Make the family handoff clear

Write down the installed version, update source and basic functions tested afterward and the name of the approved helper. The Install Updates From the Official Screen handoff is complete only when the update completes from settings and the normal task still works. Review this topic note after a relevant device, account or caregiver change.
